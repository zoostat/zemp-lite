# Getting started

Open the Scratch project, run a script, and read what each statement made.

Zemp Lite runs the Zeff engine inside this browser. Nothing is installed, there is nothing to sign up for, and your data stays on this computer.

## Run the example

1. On the screen of projects, press **Scratch project**. It holds worked examples to run and change.
2. Press **Run**, or <kbd>⌘⇧↵</kbd> (<kbd>Ctrl ⇧ ↵</kbd> on Windows and Linux). The script runs from its first statement to its last.
3. Read the note beside each statement: it says what the statement made. A note with more to show is a button; press it to unfold what the statement printed.

![The Script place after a run: the script with its line numbers, a note beside each statement saying what it made, and under the tenth line the table it printed, with a warning above it.](the-script-after-a-run)

## The four places

The words at the top of the window are the places of the app:

- **Script**: the script, with a note beside each statement.
- **Data**: the frames the last run made, as tables.
- **Plots**: the plots the last run drew.
- **Help**: a page for every function, package and code of the engine, and these pages on the app itself.

## Change something

Change a number in the script. The statement you changed is marked `edited · not run`, and the results under it `stale`, until the script is run again. Nothing you do in the Scratch project can be lost for good: it can be reset to its examples from the screen of projects.
