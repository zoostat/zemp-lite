# Keyboard shortcuts

The keys the app answers to, place by place. On Windows and Linux, Ctrl takes the place of ⌘.

## Anywhere in a project

- <kbd>⌘K</kbd>: the list of commands.
- <kbd>⌘1</kbd> to <kbd>⌘5</kbd>: the places, in the order of the icons down the left: Script, Data, Plots, Paper, Help. A browser has the same keys for its own tabs, and may keep them; each place is in the list of commands too.
- <kbd>⌘↵</kbd>: run. Outside the script it runs the whole script; with the cursor in the script, the statement at the cursor.
- <kbd>Ctrl `</kbd>: put the cursor in the console line, at the foot of the window.

## In the script

- <kbd>⌘↵</kbd>: run the statement the cursor is in, with the statements it needs.
- <kbd>⌘⇧↵</kbd>: run the whole script.
- <kbd>⌥↵</kbd>: unfold, or fold, the output of the statement the cursor is in.
- <kbd>F1</kbd>: open Help at the page of the function the cursor is on.
- <kbd>Tab</kbd> indents. To leave the script by the keyboard, press <kbd>Esc</kbd> and then <kbd>Tab</kbd>.

## In the console line

- <kbd>↵</kbd>: run the statement typed. It sees what the script made, and changes nothing in the script.
- <kbd>⌘↵</kbd>: copy the line into the script, at the cursor.
- <kbd>↑</kbd> and <kbd>↓</kbd>: bring back what was typed before.
- <kbd>Tab</kbd>: complete a name.

## In Help

- <kbd>/</kbd>: put the cursor in the search field.
- <kbd>⌘[</kbd> and <kbd>⌘]</kbd>: back and forward through the pages opened.

## In the Data and Plots places

- <kbd>⌘C</kbd>: copy the cells chosen in the table, as the engine wrote them.
- <kbd>⌥←</kbd> and <kbd>⌥→</kbd>: move a plot of the strip one place, when the Tab key rests on it.

## Everywhere

The Tab key reaches every control of the window. In a menu or a list, the arrows move and <kbd>Esc</kbd> closes it. In Safari, buttons are reached with Option held as Tab is pressed, unless Safari's own setting is changed.
