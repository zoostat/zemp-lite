summary — Table of N, missing, mean, SD, min and max                   data · tier 1 · since 0.1.0 · 1.0 · closed form

IN BRIEF
    - `d.summary()`: every variable of numbers, one row each: N, missing, mean, sd, min and max.
    - `d.summary([wage, hours])`: the variables named.
    - `d.summary([wage], stats: [n, mean, sd])`: the statistics chosen, in the order wanted.
    - `d.summary([wage], by: year)`: group by group.

USAGE
    data.summary(vars: Vars, stats: List<n | missing | mean | sd | min | max>, by: Vars, weights: Var,
                 weight_type: frequency | analytic | sampling = sampling)

DESCRIPTION
    One row per variable with its count of non-missing values (`N`), its count of missing values, and its
    mean, sample standard deviation (n − 1), minimum and maximum, computed as `mean` and `sd` compute them:
    missing values are skipped and the rows skipped are counted in one warning under the table. Without
    `vars`, every Bool, Int or Float variable is summarised, in the frame's order; a Bool variable counts
    `true` as 1. `stats:` chooses the statistics and their order from the six words `n`, `missing`, `mean`,
    `sd`, `min` and `max`; any other word is refused.

    Statistics print with three decimals, as section 10.2 of the Language Reference prints tables; `mean`
    and `sd` on their own print six significant digits. A variable whose values are all missing shows `NA`
    throughout, with a warning; one value alone has an `NA` standard deviation, and so has a variable
    holding `Inf`.

ARGUMENTS
    data          Frame. The frame.
    vars:         Vars. The variables to summarise, in a list, as in `[wage, hours]`; one may be written
                  alone. Omitted, every Bool, Int or Float variable.
    stats:        List<n | missing | mean | sd | min | max>. The statistics to show, as words in a list, in
                  the order wanted: `stats: [mean, sd]`. Omitted, all six in the order N, missing, mean, sd,
                  min, max.
    by:           Vars. Repeat the computation within each group; plots draw one panel per group.             (shared)
    weights:      Var. Weight variable.                                                                       (shared)
    weight_type:  frequency | analytic | sampling = sampling. Stata's fweight, aweight and pweight. In 1.0
                  the tests refuse `weights:` with `weight_type: sampling` (Z0411) and point to regression
                  with robust errors.                                                                         (shared)

VALUE
    A `Table`, with the `by:` variables as its first columns when groups are asked for, which prints as
    shown and can be passed to `print`.

MISSING VALUES
    Each statistic is taken over the values present. The table counts the missing values of each variable in
    a column of its own, and one warning under it counts the rows skipped. A variable whose values are all
    missing shows `NA` throughout.

DETAILS
    The mean is a compensated sum corrected once; the standard deviation is the corrected two-pass algorithm
    with the deviations scaled before squaring; see `mean` and `sd`. Minimum and maximum are taken over the
    non-missing values, so `Inf` and `-Inf` appear as themselves.

WARNINGS AND NOTES
    W0201   missing values skipped, with the count for each variable in one line; a variable with all values
            missing, or no rows at all
    W0204   Inf and -Inf both present, so a mean is NA
    W0205   one value only or an infinite value, so a sd is NA
    Z0101   no such variable in the frame
    Z0102   a variable that differs only in case from the name written
    Z0401   a variable that is not Bool, Int or Float; stats: with an empty list or a value that is not one
            of the six words
    Z0402   stats: names a word that is not a statistic

A COMMON MISTAKE
    Asking for a statistic the table does not have, such as the median. `stats:` chooses among six words:

    > dataset(wages).summary([wage], stats: [median])
    error[Z0402]: `median` is not one of the allowed words
      = help: did you mean `mean`?

    For other statistics name them yourself: `dataset(wages).aggregate(median = median(wage), p90 =
    quantile(wage, p: 0.9))`.

COMING FROM R OR STATA
    Equivalents: R summary(); Stata summarize.

    Zeff                          R                                  Stata
    d.summary([wage, hours])      summary(d[, c("wage", "hours")])   summarize wage hours
    d.summary([wage], by: year)   tapply(d$wage, d$year, summary)    tabstat wage, by(year) statistics(n mean sd min max)

    R's `summary` gives the quartiles and the mean, no standard deviation, and the count of `NA` only where
    there are some. Stata's `summarize` gives the count, the mean, the standard deviation, the minimum and
    the maximum, as here, without the count of missing values.

RELATED TASKS
    - For the type and an example of each variable, use `describe`.
    - For statistics of your own choosing, group by group, use `aggregate`.
    - For the quantiles of a variable, use `quantile`.
    - For the count of each value of a category, use `tabulate`.
    - For one statistic as a number, use `mean`.

ACCURACY
    Closed form.

REFERENCES
    Chan, Golub and LeVeque (1983), Algorithms for computing the sample variance: analysis and
    recommendations, The American Statistician 37, 242–247.

SEE ALSO
    mean, sd, describe

summary — The printed summary of a result as a table                      results · tier 1 · since 0.4.0 · 1.0 · exact

USAGE
    fit.summary(standardized: Bool = false, fit_measures: Bool = false, exponentiate: Bool = false)

DESCRIPTION
    Gives the summary a result prints, as a `Table` that can be exported: for a fitted model the title, the
    lines on the rows used and the standard errors, the table of estimates and the fit measures; for a
    test's result its title, its table if it has one, and its statistic line. `standardized: true` adds a
    column `beta` after the estimates, each estimate times the standard deviation of its regressor over that
    of the outcome, blank for the intercept and for an omitted term; `fit_measures: true` adds a line with
    the log-likelihood, AIC and BIC under the fit measures, which count the variance as a parameter as R's
    `AIC` and `BIC` do. Like R's `summary` on a fit and Stata's `regress, beta`.

    The summary of a `glm` fit gives its log-likelihood and AIC already, so `fit_measures: true` adds the
    BIC alone; `standardized: true` is for a regression and is refused on a `glm` fit (Z0401), whose
    coefficients have no one standardization.

    `exponentiate: true` gives the odds ratios of a `glm` fit with a logit link in the place of its
    coefficients. Each estimate is exp(b), under the heading `odds ratio`: the factor by which the odds are
    multiplied when the regressor rises by one. Its standard error is exp(b) times that of b, by the delta
    method, and its interval is the interval of b with each end exponentiated, so it is not symmetric about
    the ratio. The z and the p-value are those of the coefficient, since b = 0 is a ratio of 1. The
    intercept's row is the odds when every regressor is zero. A probit link and a regression are refused
    (Z0401): their coefficients are not logarithms of a ratio. Like Stata's `logit, or`, and R's
    `exp(coef(m))` with `exp(confint.default(m))`.

ARGUMENTS
    fit            Result. The result.
    standardized:  Bool = false. Whether to add the standardized coefficients.
    fit_measures:  Bool = false. Whether to add the line of fit measures.
    exponentiate:  Bool = false. Whether to give the odds ratios of a `glm` fit with a logit link, exp of
                   each coefficient, in the place of the coefficients.

VALUE
    A `Table`.

ACCURACY
    Exact.

SEE ALSO
    estimates, export, reg
