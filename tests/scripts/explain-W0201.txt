W0201 — missing values skipped by a statistic

MEANING
    A statistic skipped the rows whose variable is `NA` and says how many, so a result on fewer
    rows than the frame has is never silent. When every value is missing, or the column has no
    rows, the result is `NA`.

COMMON CAUSES
    - A variable with gaps, read as `NA` from empty cells, `NA`, `.` or an `na_values:` code.
    - A frame with no rows left.
    - A `summary` over several variables with gaps: one line names them all.

EXAMPLE
    > wages.mean(hours)
    37.5
    warning[W0201]: 1 row with NA in hours was skipped (line 2)

FIX
    Nothing, if skipping is what you mean; otherwise look at the rows with
    `where(is_missing(hours))` (release 0.2.0) and decide how to treat them.
